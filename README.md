# Sitio CMS Template Base

Base inicial del proyecto "Sitio web informativo proyectado a CMS template".

## Estado actual
- Proyecto base creado con Next.js
- Estructura mínima inicial creada
- Separación base entre app, data, lib, components, styles y docs
- Repositorio preparado para crecer de forma ordenada

## Estructura base
- `src/app` Entrada de aplicación
- `src/components/ui` Componentes reutilizables base
- `src/components/sections` Secciones de página
- `src/data` Datos desacoplados
- `src/lib/theme` Resolución temática
- `src/lib/content` Registro y mapeo de contenido
- `src/lib/utils` Utilidades compartidas
- `src/styles/themes` Themes del sistema
- `public/assets` Recursos estáticos
- `docs` Documentación interna
