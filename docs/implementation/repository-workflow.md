# Repository workflow

## Ramas base
- main: rama estable
- develop: rama de integración

## Regla mínima de trabajo
- no trabajar directamente sobre main
- trabajar sobre develop o ramas derivadas
- hacer commits pequeños y claros
- no mezclar cambios de arquitectura, datos y UI sin necesidad

## Formato sugerido de ramas
- feat/base-setup
- feat/theme-foundation
- feat/data-contracts
- feat/ui-base
- feat/sections-foundation
